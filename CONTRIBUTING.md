# Contributing to Wendy

Please send changes through a pull request from your fork:

1. Fork the repository and create a branch for your change.
2. Make the change and run `python tools/build.py` from the repository root.
3. Open a pull request from your branch to `AdysonLN/wendy:main`.
4. Explain what changed and how you checked it. For screen or control changes,
   mention whether you tested them on a controller and which VirtualDJ version
   you used.

The maintainer reviews and merges contributions. Direct repository write access
is reserved for the maintainer, who also retains the ability to push directly
to `main` and publish releases.
